One weird job title for make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty, $5 in USDC. A blind judge compares titles two at a time and picks the weirder, funnier one — so this entry pairs a dead-serious corporate title with the least corporate duty imaginable.

> Senior Vice President of Apologizing to Geese

## Run it

```sh
node main.ts
```

This writes the title to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), exactly 45 characters, no trailing newline.
